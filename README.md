# TG MATRIX KIT — APK

Тот же терминал выгрузки Telegram-чатов, что и [tg-matrix-kit](https://github.com/kipingame-cell/tg-matrix-kit), но **целиком в виде Android-приложения**. Сервер не нужен: GramJS работает прямо внутри WebView, телефон сам ходит в Telegram.

## Возможности (1 в 1 с серверной версией)

- Вход по номеру: код в приложение Telegram / SMS / звонок (кнопка переключения канала), поддержка 2FA.
- Маскировка под официальный клиент: Samsung Galaxy S23 Ultra, Android 13.0, клиент 9.6.5.
- База чатов с поиском, сортировкой, кнопкой ⟳ обновления; выбранный чат и база кэшируются.
- Выгрузка: лимит, ключевые слова, фильтр участника, даты, только текст.
- Монитор перехвата в реальном времени, кнопка СТОП.
- ZIP-архив: messages.txt / messages.json / graph.graphml / heatmap.json / dossier.txt — сохраняется в **Документы/tgkit_exports/**.
- Граф связей: типизированные связи (ответы/упоминания/реакции), слайдер силы связи, кластеры, досье по узлу.
- Радар: линия «ВЕСЬ ЧАТ», сравнение двух периодов.
- Пуш ботом: по завершении выгрузки шлёт ZIP в Telegram (токен и chat_id в «КЛЮЧИ И ИНТЕГРАЦИИ»).
- Досье НКВД через Gemini (свой ключ).
- Сессия сохраняется в приложении — повторный вход не нужен.

## Как получить APK

### Вариант 1: GitHub Actions (рекомендуется)

1. Включи сборку: создай в репозитории файл `.github/workflows/build.yml` и вставь туда содержимое `build-apk.yml.txt` (у меня нет права пушить workflow-файлы через API — поэтому этот шаг вручную, один раз).
2. Actions → Build APK → запустится автоматически после пуша.
3. Через ~5–10 минут забери артефакт **tg-matrix-kit-apk** (app-debug.apk).
4. Закинь на телефон, установи (разреши «из неизвестных источников»).

### Вариант 2: локальная сборка (нужен Android SDK)

```bash
npm install
npm run build
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

## Отличия от серверной версии

- Нет Tor — соединение прямое (WebSocket). Если Telegram заблокирован сетью, включи VPN на телефоне.
- Выгрузка идёт, пока открыто приложение. Кнопка «Домой» сворачивает — Android может усыпить WebView, поэтому для больших выгрузок держи экран включённым.
- Досье и пуш ботом работают напрямую из приложения.

## Безопасность

- Сессия Telegram хранится только в локальном хранилище приложения.
- Ключи (бот, Gemini) — тоже только локально, ничего не уходит на сторонние серверы, кроме официальных API Telegram и Google (если включено досье).
- Репозиторий не содержит секретов.
