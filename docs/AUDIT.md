Тип: Android · Telegram. Версия из фактических источников: **1.0.0**.

Файлов исходного дерева: **15**. Прочитано доступных текстовых файлов для проверки: **14**. Кэши, бинарные сессии и крупные двоичные файлы не исполнялись. Файлы APK проверяются в предназначенном для них CI.

## Выявленные проблемы

- P0: в публичном репозитории находится tgk.keystore.b64 — ключ подписи доступен из исходников и истории.
- P1: миграцию ключа в Actions Secrets провести с сохранением существующего сертификата; удаление файла само по себе не отменяет раскрытие.
- P1: версия package.json не различает многочисленные сборки; связать APK versionCode с номером сборки.
- P1: часть Releases оформлена нестандартно; новые публикации должны иметь нормальный тег, commit SHA и checksum.

- Обложка и отдельная схема проекта. Обложка — иллюстрация, а не изображение работающего интерфейса.
- Этот аудит и отдельный реестр версий. Подробные исходные материалы сохранены.

P0 — раскрытие доступа или опасная эксплуатационная конфигурация; P1 — воспроизводимость, работоспособность или поставка; P2 — поддерживаемость. Это приоритеты обнаруженных задач, а не заявление о выполнении всех предложений.
